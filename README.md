# CortaAI - SaaS de cortes virais com IA

## Rodar local
```
yarn install
yarn dev
```
Abre http://localhost:3000

## Deploy na Vercel
1. Sobe esse projeto num repo GitHub
2. Em vercel.com > New Project > Import Repository
3. Framework preset: Next.js (auto-detectado)
4. Deploy — sem env vars obrigatórias (tudo é localStorage)
